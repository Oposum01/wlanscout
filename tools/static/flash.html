wlanscout+ flasher v@VERSION@

Writes wlanscout+ to an ESP32-C5: bootloader, partition table, boot selection and firmware, each to its own address as the Arduino IDE does. Settings and the IE catalog on the board stay. Plug the board's USB-C port marked USB (not UART) into the phone. A new board needs no button; if it does not connect, hold BOOT while plugging it in.
State: idle
