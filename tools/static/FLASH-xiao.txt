wlanscout firmware @VERSION@ for the Seeed Studio XIAO ESP32-C5 (8 MB flash, PSRAM enabled)

Built with BOARD_ID "xiao" and Ethernet off (config.h). Partition
table: two 3.25 MB firmware slots (app0/app1) for updates from the page
over USB, 1.4 MB LittleFS for the IE catalog, the snapshots and the
event log (source/wlanscout/partitions_xiao.csv).

A) Sensor already running wlanscout: update from the page over USB
   Settings -> Sensor -> "Check for new firmware", or choose
   firmware/xiao/wlanscout.ino.bin -> "Upload and restart". Settings,
   IE catalog and snapshots stay.

B) Over USB with esptool, settings, IE catalog and snapshots kept

   esptool --chip esp32c5 --port /dev/ttyACM0 --baud 921600 write-flash \
     --flash-mode dio --flash-freq 80m --flash-size 8MB \
     0x2000  wlanscout.ino.bootloader.bin \
     0x8000  wlanscout.ino.partitions.bin \
     0xe000  boot_app0.bin \
     0x10000 wlanscout.ino.bin

   For an update the last line alone does.

C) Fresh device / everything from scratch: merged image at 0x0
   Overwrites the whole 8 MB flash, settings (NVS), catalog and
   snapshots included.

   esptool --chip esp32c5 --port /dev/ttyACM0 --baud 921600 write-flash 0x0 wlanscout.ino.merged.bin

D) From a phone, without a PC: flash.html of the repository published
   on GitHub Pages, board "Seeed Studio XIAO ESP32-C5"; see docs/usb.md.

If nothing answers on USB: hold BOOT, press RESET, release BOOT; the
board is then in its download mode for any of the above.

Older esptool (v4): use "esptool.py" and "write_flash" instead of "esptool" / "write-flash".
